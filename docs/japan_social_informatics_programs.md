# 日本社会信息学/计算社会科学修士申请检索手册（教授信息增强版）

> 版本说明：在“东大10、京大10、其余各校5”数量结构不变的前提下，补充了每位导师的申请实用字段（研究特色、申请匹配、能力偏好、语言提示、核验入口）。

## 使用说明
- 本文用于**申请准备与导师初筛**，最终以各校当年募集要项、研究科官网、实验室主页为准。
- “能力偏好/语言提示”为基于公开项目特点的申请导向判断，建议你在联系前二次核验。
